J.A.C.O. — Reglamento Web

Esta versión mantiene el contenido original del reglamento y aplica una estética inspirada en la referencia proporcionada:
- Fondo negro con textura/grunge y acentos rojos.
- Tipografía más manuscrita/gótica para títulos y navegación.
- Uso del emblema J.A.C.O. como pieza visual principal.
- Tarjetas del reglamento con bordes, líneas y detalles rojos.
- Diseño responsive para celular y PC.

Abrir index.html en un navegador. La tipografía de Google Fonts requiere conexión a Internet; si no hay conexión se usan fuentes de respaldo.
